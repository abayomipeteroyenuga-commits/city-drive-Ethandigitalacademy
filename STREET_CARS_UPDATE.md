CITY DRIVE — STREET CARS EXPANSION

Added a street-car catalog covering:
- sedans
- hatchbacks
- SUVs
- MPVs
- taxis
- delivery vans
- pickups

The names are fictionalized real-world-inspired vehicle types so the game does not
depend on copyrighted manufacturer logos/assets.

Added traffic configuration for up to 24 street vehicles and a conservative adapter
that uses the game's native spawnTrafficCar API if it exists.

The existing playable vehicle/physics system is preserved.
